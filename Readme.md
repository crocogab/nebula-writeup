# Nebula — Linux Exploitation

Dépôt personnel dédié à l'apprentissage et à la révision de l'**exploitation de binaires
Linux** via [Nebula](https://exploit.education/nebula/) (Exploit Education).

L'objectif est de reprendre en profondeur les fondamentaux de l'exploitation locale sous
Linux : permissions SUID, variables d'environnement, manipulation du `$PATH`, race
conditions, format strings et scripts vulnérables.

## Organisation

Chaque challenge dispose de son propre dossier contenant un writeup détaillé.
Structure : 

```
Nebula/
├── Challenge00/
│   └── Writeup00.md
├── Challenge01/
│   └── Writeup01.md
├── ...
└── Readme.md
```
